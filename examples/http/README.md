# A proved HTTP/1.1 request head parser, called from C

The request line and header fields of an HTTP/1.1 message (RFC 9112), as a
library written in Bastio. The bytes come from a socket, so they are
untrusted: a length or a delimiter read without care sends a parser past its
buffer, and a parser that is lenient about line endings or folding lets one
request be read two ways by two servers (request smuggling).

| File | What it is |
| --- | --- |
| `http.bastio` | The library: `export fn http_parse_head` and `http_field`. Proved |
| `test.c` | The C harness: vectors, every prefix of a well-formed head, a differential fuzz against an independent state-machine parser |
| `run.sh` | Generates `http.c` and `http.h`, then builds and runs the harness under AddressSanitizer + UBSan |

```c
#include "http.h"   /* generated by bastioc0 --header */

bst_e_Head h = http_parse_head(buf, len);
if (h.tag == bst_e_Head_Ok) {
    /* method buf[0..h.u.Ok.method_end), target buf[target..target_end),
       body at buf[h.u.Ok.head_end..); walk the fields with http_field */
} else if (h.tag == bst_e_Head_Partial) {
    /* read more and call again */
}
```

The parser allocates nothing; it returns offsets into `buf`.

## What is proved

For every input, with no runtime check in the generated code:
- no read outside `buf[0..len)` and no overflow;
- the `ensures` clauses: the method, target and first field lie in this
  order inside the input, the head ends inside the input, the version is
  HTTP/1.0 or HTTP/1.1, and every field's name, value and next-line offsets
  are in order and inside the input.

**Not proved:** that exactly the heads RFC 9112 allows are accepted. The
parser is strict (CR LF only, no control characters, no space before the
colon, no line folding, one space between request-line parts), and `test.c`
checks it against vectors and an independently written state machine. It
reads whole lines, so it may report an incomplete head where the state
machine already sees a violation.

Also builds as WebAssembly: `bastioc1 --arch wasm32 examples/http/http.bastio`.
